# LuxeFolio — Premium Portfolio Generator

A beautiful, client-side **Portfolio Generator** that lets anyone create a professional portfolio in minutes.

## Features

- **Live Preview** — See your portfolio update in real time
- **Generate Bio** — One-click professional bio from your details
- **Programming Languages** — Special section for Python, JavaScript, TypeScript, Go, Rust, etc.
- **Skills & Tools** — Dynamic tags
- **Projects** — Add multiple projects with tech stack, live link & GitHub
- **Experience** — Timeline-style work history
- **Social Links** — GitHub, LinkedIn, X, Instagram, YouTube, Website
- **Theme Options** — Modern, Luxury/Elegant, Minimal, Bold
- **Accent Colors** — Indigo, Violet, Emerald, Rose, Amber, Gold
- **Dark / Light Mode**
- **Mobile Preview Toggle**
- **Save to Browser** (localStorage)
- **Download** — Export a complete standalone HTML portfolio ready to host

## How to Use

1. Open `index.html` in any modern browser
2. Fill in your details (or click **Sample** to load demo data)
3. Click **Generate Bio** for a polished About section
4. Add languages, skills, projects and experience
5. Choose your preferred style and accent color
6. Click **Download** to get your portfolio HTML file

## Deploy on GitHub Pages

1. Create a new repository on GitHub
2. Upload the `index.html` file (and this README if you want)
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch`
5. Choose `main` branch and `/ (root)`
6. Click Save

Your generator will be live at:  
`https://yourusername.github.io/your-repo-name`

### Deploy the generated portfolio

After downloading your personal portfolio HTML:

1. Create another repo (or a `/portfolio` folder)
2. Rename the downloaded file to `index.html`
3. Enable GitHub Pages the same way

## Tech Stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- Font Awesome icons
- Google Fonts (Inter + Playfair Display)

No backend, no build step, no dependencies to install.
